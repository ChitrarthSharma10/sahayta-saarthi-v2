# Capacity Connect – Frontend Client

Modern dark glassmorphic React 19 + Vite 8 frontend for Capacity Connect Enterprise LMS.

## Technologies Used

- **React 19** (`react`, `react-dom`)
- **Vite 8** with `@vitejs/plugin-react`
- **Tailwind CSS** with custom radial gradients and glassmorphism
- **Framer Motion** for physics-based 3D tilt hover effects and animations
- **ShaderGradient** (`@shadergradient/react`, `@react-three/fiber`, `three`) for 3D WebGL background visuals
- **Recharts** for performance trends and analytics
- **Lucide React** for icons
- **Zustand** & **Context API** for state management

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

App runs on **http://localhost:5173**.

## Production Build

```bash
npm run build
npm run preview
```
